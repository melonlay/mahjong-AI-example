# 麻將牌 AI 圖像分析工具 (聚類與分類)

## 重要聲明

**本專案僅作為技術演示與教育目的，講解訓練用於麻將牌圖像分析（包括聚類與分類）的 AI 模型的流程。專案本身不提供任何預先訓練好的模型權重 (`.pth` 文件) 或可用於實際應用的麻將 AI。使用者需要自行收集數據並完成模型訓練步驟。此外，請注意，本文件所述的方法並非實現麻將牌圖像分析的唯一途徑，存在多種不同的技術和策略可以達成相似的目標。**

## 專案目標

本工具旨在演示使用 AI 技術，對擷取到的麻將牌圖片進行自動分析，包括使用非監督式**聚類**來輔助數據整理，以及訓練**分類**模型來識別牌張。目標是從零開始，透過收集數據、訓練模型，最終將未知的麻將牌圖片（來自 `capture/` 目錄）分類到 `clustered_tiles/` 目錄下的不同簇中，並使用訓練好的分類器進行精確識別和整理。專案針對三人麻將，目標是將牌張分為 29 類。

## 從零開始的完整工作流程

以下是從沒有數據和模型開始，到最終能夠訓練並使用聚類和分類模型的完整步驟：

### 步驟 1：環境設置

1.  **Python**: 確保已安裝 Python (建議 3.8 或更高版本)。
2.  **依賴庫**: 安裝所需的 Python 庫。打開終端或命令提示字元，運行：
    ```bash
    pip install torch torchvision opencv-python numpy scikit-learn Pillow tensorboard
    ```
    *   **重要**: 為了獲得最佳性能（尤其是在訓練時利用 GPU），請務必根據您的作業系統、Python 版本和 CUDA 版本（如果您有 NVIDIA GPU 並安裝了 CUDA）參考 [PyTorch 官方網站](https://pytorch.org/) 的說明來安裝 `torch` 和 `torchvision`。

**此步驟目的：** 為專案準備必要的運行基礎。Python 是程式語言本身，而各個依賴庫提供了關鍵功能：`torch` 和 `torchvision` 用於深度學習模型訓練與圖像處理，`opencv-python` 用於圖像讀取和基本操作，`numpy` 用於數值計算，`scikit-learn` 用於聚類算法和評估，`Pillow` 用於圖像處理，`tensorboard` 用於視覺化訓練過程。

### 步驟 2：利用初步聚類創建初始訓練數據基礎

此步驟的目標是從完全未標記的圖像開始，利用**預定義的聚類方法**創建一個初步分類的數據集，以減輕後續手動標註和整理的負擔。

1.  **收集初始未分類圖片**: 將您收集到的所有麻將牌圖片（無需手動分類）先放入 `capture/` 目錄。
    *   **提示:** 您可以運行 `python main.py` 來啟動圖形介面 (GUI)。此介面可能包含螢幕擷取、手牌區域選取 (ROI) 和牌面切割等功能，可以**極大地幫助您**從遊戲畫面或其他來源收集並切割出單張麻將牌圖片，並將其保存到 `capture/` 目錄。
2.  **執行初步聚類 (使用備選方法)**: 運行聚類腳本。由於此時還沒有自訂模型，腳本會**自動使用備選方法** (基於預訓練 ResNet18 + 顏色特徵) 進行聚類。
    ```bash
    # 確保從專案根目錄運行
    python tools/cluster_captured_tiles.py
    ```
3.  **檢查並整理初步結果**: 腳本執行完畢後，`clustered_tiles/` 目錄下會生成初步的聚類結果（例如 `cluster_00`, `cluster_01`, ...）。現在需要進行**人工審核和整理**，為後續訓練**自訂聚類器**和**分類器**準備基礎數據：
    *   創建 `./data` 目錄（如果尚未存在）。
    *   在 `./data` 下，為每一種麻將牌（當前目標為 29 種）創建對應的子目錄 (例如 `1m`, `Aka5p`, `N` 等)。同時，創建一個 `noise` 子目錄 (`./data/noise/`)，用於存放非麻將牌的圖片（例如背景、特效閃光、無法識別的圖像等）。
    *   **逐一檢查** `clustered_tiles/` 下的每個 `cluster_XX` 子目錄。理想情況下，一個簇裡大部分應該是同一種牌。
    *   將每個 `cluster_XX` 目錄中**確認屬於同一種牌**的圖片，**移動**到 `./data/` 目錄下對應的**正確類別子目錄**中。例如，如果 `cluster_05` 大部分是「一萬」，則將其中所有「一萬」的圖片移動到 `./data/1m/`。
    *   對於明顯錯誤分類的圖片（例如「一萬」簇裡混入了「北風」），將其移動到 `./data/` 下正確的類別子目錄中（例如 `./data/N/`）。
    *   如果發現一些非麻將牌的圖片（如背景、閃光）被錯誤地聚類，將它們移動到 `./data/noise/` 目錄。如果某些圖片質量太差或無法識別，也可以放入 `noise` 目錄或直接捨棄。
4.  **完成第一版訓練集**: 當您整理完 `clustered_tiles/` 中的所有可用圖片後，`./data/` 目錄就包含了您的第一版、帶有（相對）準確標籤的訓練數據集。

**此步驟目的：** 解決從零開始時缺少標註數據的問題。利用機器初步聚類的能力，將完全手動分類的繁重任務轉變為**審核和修正**的任務，大大提高創建初始訓練集的效率。生成的 `./data/` 目錄是後續訓練自訂聚類模型和分類模型的基礎。

### 步驟 3：訓練第一個自訂聚類特徵提取模型

使用上一步創建的第一版 `./data/` 數據集，訓練您的第一個**自訂聚類特徵提取模型** (使用 Supervised Contrastive Learning)。這個模型的目標是學習一個好的特徵空間，使得相同類別的麻將牌在該空間中距離更近。

1.  **運行聚類訓練腳本**: 確保 `--data_dir` 指向您整理好的 `./data` 目錄。
    ```bash
    # 建議從專案根目錄運行
    python trainer/clustering/train.py --data_dir ./data --output_dir trainer/clustering --epochs 100 --batch_size 128 --lr 5e-4 --save_top_k 3 [其他參數...]
    ```
    *   `--data_dir ./data`: 指定包含已分類訓練圖片的目錄。
    *   `--output_dir trainer/clustering`: 指定保存訓練日誌和模型文件的目錄。
    *   `--epochs 100`: 訓練輪數（SupCon 可能需要較多輪數）。
    *   `--batch_size 128`: 批次大小（對比學習通常需要較大批次）。
    *   `--lr 5e-4`: 學習率。
    *   `--save_top_k 3`: 保存驗證集 ARI 指標最高的 3 個模型（可調整）。
    *   *(查看 `trainer/clustering/train.py` 腳本獲取更多可用參數)*
2.  **獲取自訂聚類模型**: 訓練完成後，表現最好的 K 個模型會保存在 `trainer/clustering/result/` 目錄下，文件名類似 `model_epoch_XX_ari_Y.YYYY.pth`。

**此步驟目的：** 基於初步整理的數據，生成第一個針對麻將牌進行優化的**特徵提取器**。雖然訓練數據可能還不完美，但這個模型學習到的特徵通常會比通用的 ResNet18 更適合用於後續的麻將牌聚類任務。

### 步驟 4：準備新的待聚類圖片

收集您希望使用**已訓練好的自訂聚類模型**來自動聚類的**新的**麻將牌圖片。

1.  **清空或填充 `capture/` 目錄**: 將這些**新的、未分類的**圖片放入 `capture/` 目錄中。

**此步驟目的：** 提供需要用**已優化模型**進行聚類的實際輸入數據。

### 步驟 5：使用自訂模型執行圖像聚類

利用步驟 3 訓練好的**最佳自訂聚類模型**，對步驟 4 中準備的新圖片進行聚類。

1.  **運行聚類腳本**: 再次運行聚類腳本，這次使用 `--model_path` 參數指定您想要使用的模型文件路徑。
    ```bash
    # 將 <path_to_your_best_cluster_model.pth> 替換為實際的模型文件路徑
    # 例如 trainer/clustering/result/model_epoch_XX_ari_Y.YYYY.pth
    python tools/cluster_captured_tiles.py --model_path <path_to_your_best_cluster_model.pth>
    ```
    *   **注意**: 如果省略 `--model_path` 參數，或者提供的路徑無效（文件不存在或無法加載），腳本會**自動回退**到使用備選方法（預訓練 ResNet18 + 顏色特徵）進行聚類，並在日誌中顯示警告。
2.  **處理過程**: 如果提供了有效的模型路徑，腳本這次會：
    *   **成功加載**您通過 `--model_path` 指定的自訂聚類模型。
    *   讀取 `capture/` 中的**新**圖片。
    *   使用**自訂模型**為每張新圖片提取特徵向量。
    *   使用 `AgglomerativeClustering` 將這些特徵向量聚類成 **30** 個簇（因為我們包含了 noise）。
    *   將 `capture/` 中的新圖片根據聚類結果複製到 `clustered_tiles/` 目錄下對應的簇子目錄中。

**此步驟目的：** 應用**經過優化的自訂聚類模型**來處理新的、未知的數據，期望獲得比步驟 2 初步聚類更準確的聚類結果。

### 步驟 6：查看結果與迭代優化聚類器

*   檢查 `clustered_tiles/` 目錄中**使用自訂聚類模型**得到的最新聚類結果。
*   評估聚類效果。通常這次的結果會比步驟 2 的初步結果更準確。
*   **(可選) 迭代優化聚類器**: 如果您希望進一步提升**聚類模型**的效果，可以仔細審核這次 `clustered_tiles/` 中的結果，將分類**正確**的圖片（包括被正確聚類到某個牌簇的牌，以及被正確聚類到代表 noise 的簇的 noise 圖片）按其**真實類別**（包括 `noise` 類別）**添加**回 `./data/` 目錄，以**擴充和精煉**您的訓練數據集。然後，您可以選擇性地回到**步驟 3**，使用更新後的 `./data/` **重新訓練聚類模型**，以期獲得進一步的性能提升。重複此過程（步驟 3 -> 步驟 4 -> 步驟 5 -> 步驟 6 -> 更新數據 -> 步驟 3...）可以不斷優化聚類模型。

**此步驟目的：** 評估自訂聚類模型的效果，並提供一個持續改進聚類模型的路徑。通過不斷地用模型處理新數據，並將驗證過的結果反哺回訓練集，可以逐步提升聚類模型的特徵提取能力。

### 步驟 7: 訓練分類模型 (Classification)

在通過聚類輔助整理和手動標註，確保 `./data/` 目錄下包含帶有準確標籤的訓練數據（每個子目錄代表一個類別，**且包含 `noise` 類別**）後，您可以開始訓練一個**分類模型**。這個模型的目標是直接預測輸入圖片屬於哪個具體的類別（例如 "1m", "Wh", "noise"）。

1.  **確認訓練數據**: 再次檢查 `./data/` 目錄及其子目錄，確保數據已按類別整理好，並且 `noise` 目錄包含了代表性的非麻將牌圖片。
2.  **運行分類訓練腳本**: 執行 `trainer/classification/train.py` 腳本。
    ```bash
    # 建議從專案根目錄運行
    python -m trainer.classification.train --data_dir ./data --output_dir trainer/classification/results --epochs 50 --batch_size 128 --lr 0.001 --save_top_k 3 --num_workers 4
    ```
    *   `--data_dir ./data`: 指定包含已分類訓練圖片的目錄。
    *   `--output_dir trainer/classification/results`: 指定保存訓練日誌和模型文件的目錄。
    *   `--epochs 50`: 訓練輪數（可調整）。
    *   `--batch_size 128`: 批次大小（可根據 GPU 記憶體調整）。
    *   `--lr 0.001`: 學習率。
    *   `--save_top_k 3`: 保存驗證準確率最高的 3 個模型（可調整）。
    *   `--num_workers 4`: 數據加載線程數。
    *   *(查看 `trainer/classification/train.py` 腳本獲取更多可用參數)*
3.  **獲取分類模型**: 訓練完成後，表現最好的 K 個模型會保存在 `trainer/classification/results/models/` 目錄下，文件名類似 `model_epoch_XX_acc_Y.YYYY.pth`。

**此步驟目的：** 訓練一個監督式學習模型，使其能夠對輸入的麻將牌圖片（或非麻將牌圖片）進行明確的類別預測。這個模型是後續進行自動分類、推論和整理任務的基礎。

### 步驟 8：利用分類器進行之後的工作 (推論與整理)

訓練好**分類模型**後，您可以使用它來對一批新的、未標記的圖片進行預測，並將這些圖片自動整理到以預測類別命名的資料夾中。

1.  **準備待分類圖片**: 將您想要進行分類的圖片放入一個資料夾，例如 `./capture` 目錄。
2.  **找到訓練好的分類模型**: 在 `trainer/classification/results/models/` 目錄下找到您想要使用的分類模型文件（`.pth` 文件），例如 `model_epoch_XX_acc_Y.YYYY.pth`。
3.  **運行推論與整理腳本**: 執行 `tools/infer_and_organize.py` 腳本。
    ```bash
    python tools/infer_and_organize.py --model_path <你的模型路徑.pth> --input_dir ./capture --output_dir ./test_inference
    ```
    *   將 `<你的模型路徑.pth>` 替換為您實際選擇的分類模型文件路徑。
    *   `--input_dir`: 指定包含待分類圖片的目錄（預設為 `./capture`）。
    *   `--output_dir`: 指定保存整理結果的目錄（預設為 `./test_inference`，如果已存在會被清空）。
4.  **查看推論結果**: 腳本執行完成後，檢查 `./test_inference/` 目錄。腳本會根據模型的預測，為每個預測出的類別（例如 `1m`, `Wh`, `noise` 等）創建子目錄，並將對應的原始圖片複製到這些子目錄中。

**此步驟目的：** 提供一個使用**已訓練好的分類模型**直接對新圖片進行預測並自動整理檔案的方法，方便快速查看模型的實際分類效果，或用於後續的其他應用。

## 注意事項

*   **數據質量是核心**: 無論是初始整理（步驟 2）還是後續迭代（步驟 6），仔細審核和標註數據都是提升模型性能的關鍵。
*   **訓練時間**: 模型訓練（聚類特徵提取或分類）可能需要較長時間，具體取決於數據量和硬體。
*   **迭代改進**: 如步驟 6 所述，利用新數據和模型反覆訓練**聚類模型**是提高其特徵提取效果的常用方法。分類模型的訓練通常在數據標籤相對固定後進行。
*   **區分聚類與分類**: 請注意聚類（Clustering，目標是學習好的特徵表示以區分不同組）和分類（Classification，目標是將輸入映射到已知標籤）的目標和訓練方法不同。
