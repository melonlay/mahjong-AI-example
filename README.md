# 麻將牌 AI 聚類工具

## 重要聲明

**本專案僅作為技術演示與教育目的，講解訓練一個用於麻將牌聚類的 AI 模型的流程。專案本身不提供任何預先訓練好的模型權重 (`.pth` 文件) 或可用於實際應用的麻將 AI。使用者需要自行收集數據並完成模型訓練步驟。此外，請注意，本文件所述的方法並非實現麻將牌聚類的唯一途徑，存在多種不同的技術和策略可以達成相似的目標。**

## 專案目標

本工具使用 AI 技術，自動將擷取到的麻將牌圖片進行非監督式聚類。目標是從零開始，透過收集數據、訓練模型，最終將未知的麻將牌圖片（來自 `capture/` 目錄）分類到 `clustered_tiles/` 目錄下的不同簇中。專案針對三人麻將，目標是將牌張分為 29 類。

## 從零開始的完整工作流程

以下是從沒有數據和模型開始，到最終獲得聚類結果的完整步驟：

### 步驟 1：環境設置

1.  **Python**: 確保已安裝 Python (建議 3.8 或更高版本)。
2.  **依賴庫**: 安裝所需的 Python 庫。打開終端或命令提示字元，運行：
    ```bash
    pip install torch torchvision opencv-python numpy scikit-learn Pillow
    ```
    *   **重要**: 為了獲得最佳性能（尤其是在訓練時利用 GPU），請務必根據您的作業系統、Python 版本和 CUDA 版本（如果您有 NVIDIA GPU 並安裝了 CUDA）參考 [PyTorch 官方網站](https://pytorch.org/) 的說明來安裝 `torch` 和 `torchvision`。

**此步驟目的：** 為專案準備必要的運行基礎。Python 是程式語言本身，而各個依賴庫提供了關鍵功能：`torch` 和 `torchvision` 用於深度學習模型訓練與圖像處理，`opencv-python` 用於圖像讀取和基本操作，`numpy` 用於數值計算，`scikit-learn` 用於聚類算法和評估，`Pillow` 用於圖像處理。

### 步驟 2：利用初步聚類創建初始訓練數據

此步驟的目標是從完全未標記的圖像開始，創建第一版帶有標籤的訓練數據集 (`./data/`)，以減輕純手動分類的負擔。

1.  **收集初始未分類圖片**: 將您收集到的所有麻將牌圖片（無需手動分類）先放入 `capture/` 目錄。
    *   **提示:** 您可以運行 `python main.py` 來啟動圖形介面 (GUI)。此介面可能包含螢幕擷取、手牌區域選取 (ROI) 和牌面切割等功能，可以**極大地幫助您**從遊戲畫面或其他來源收集並切割出單張麻將牌圖片，並將其保存到 `capture/` 目錄。
2.  **執行初步聚類 (使用備選方法)**: 運行聚類腳本。由於此時還沒有自訂模型，腳本會自動使用備選方法 (ResNet18 + 顏色特徵) 進行聚類。
    ```bash
    python tools/cluster_captured_tiles.py
    ```
3.  **檢查並整理初步結果**: 腳本執行完畢後，`clustered_tiles/` 目錄下會生成初步的聚類結果（例如 `cluster_00`, `cluster_01`, ...）。現在需要進行**人工審核和整理**：
    *   創建 `./data` 目錄（如果尚未存在）。
    *   在 `./data` 下，為每一種麻將牌（共 29 種）創建對應的子目錄 (例如 `1m`, `Aka5p`, `N` 等)。
    *   **逐一檢查** `clustered_tiles/` 下的每個 `cluster_XX` 子目錄。理想情況下，一個簇裡大部分應該是同一種牌。
    *   將每個 `cluster_XX` 目錄中**確認屬於同一種牌**的圖片，**移動**到 `./data/` 目錄下對應的**正確類別子目錄**中。例如，如果 `cluster_05` 大部分是「一萬」，則將其中所有「一萬」的圖片移動到 `./data/1m/`。
    *   對於明顯錯誤分類的圖片（例如「一萬」簇裡混入了「北風」），將其移動到 `./data/` 下正確的類別子目錄中（例如 `./data/N/`）。如果某些圖片質量太差或無法識別，可以暫時捨棄。
4.  **完成第一版訓練集**: 當您整理完 `clustered_tiles/` 中的所有可用圖片後，`./data/` 目錄就包含了您的第一版、帶有（相對）準確標籤的訓練數據集。

**此步驟目的：** 解決從零開始時缺少標註數據的問題。利用機器初步聚類的能力，將完全手動分類的繁重任務轉變為**審核和修正**的任務，大大提高創建初始訓練集的效率。生成的 `./data/` 目錄是後續訓練自訂模型的基礎。

### 步驟 3：訓練第一個自訂特徵提取模型

使用上一步創建的第一版 `./data/` 數據集，訓練您的第一個自訂 CNN 模型。

1.  **運行訓練腳本**: 確保 `--data_dir` 指向您整理好的 `./data` 目錄。
    ```bash
    python trainer/clustering/train.py --data_dir ./data --output_dir trainer/clustering --epochs 150 --batch_size 128 --lr 5e-4 --temperature 0.1 --image_size 96 --num_workers 4 --seed 42 --eval_freq 10 --save_freq 50
    ```
    *   (參數說明同前)

2.  **獲取第一個自訂模型**: 訓練完成後，最佳模型權重會保存在 `trainer/clustering/result/best_mahjong_feature_extractor.pth`。

**此步驟目的：** 基於初步整理的數據，生成第一個針對麻將牌進行優化的特徵提取器。雖然訓練數據可能還不完美，但這個模型通常會比通用的 ResNet18 表現更好，為後續更精確的聚類打下基礎。

### 步驟 4：準備新的待分類圖片

收集您希望使用**已訓練好的自訂模型**來自動分類的**新的**麻將牌圖片。

1.  **清空或填充 `capture/` 目錄**: 將這些**新的、未分類的**圖片放入 `capture/` 目錄中。

**此步驟目的：** 提供需要用**已優化模型**進行分類的實際輸入數據。

### 步驟 5：使用自訂模型執行圖像聚類

利用步驟 3 訓練好的自訂模型，對步驟 4 中準備的新圖片進行分類。

1.  **確認模型存在**: 確保 `trainer/clustering/result/best_mahjong_feature_extractor.pth` 文件存在。
2.  **運行聚類腳本**: 再次運行聚類腳本。
    ```bash
    python tools/cluster_captured_tiles.py
    ```
3.  **處理過程**: 腳本這次會：
    *   **成功加載**步驟 3 訓練好的自訂模型。
    *   讀取 `capture/` 中的**新**圖片。
    *   使用**自訂模型**為每張新圖片提取特徵向量。
    *   使用 `AgglomerativeClustering` 將這些特徵向量聚類成 29 個簇。
    *   將 `capture/` 中的新圖片根據聚類結果複製到 `clustered_tiles/` 目錄下對應的簇子目錄中。

**此步驟目的：** 應用**經過優化的自訂模型**來處理新的、未知的數據，期望獲得比步驟 2 初步聚類更準確的分類結果。

**備選聚類方法說明：**
*   該方法主要用於**步驟 2** 的初始數據整理階段。雖然腳本在自訂模型加載失敗時仍會回退到此方法，但在正常迭代流程中（步驟 5），預期是使用自訂模型。

### 步驟 6：查看結果與迭代優化

*   檢查 `clustered_tiles/` 目錄中**使用自訂模型**得到的最新聚類結果。
*   評估聚類效果。通常這次的結果會比步驟 2 的初步結果更準確。
*   **(可選) 迭代優化**: 如果您對結果滿意，可以考慮將這次 `clustered_tiles/` 中分類正確的圖片，按類別**添加**回 `./data/` 目錄，以**擴充和精煉**您的訓練數據集。然後，您可以選擇性地回到**步驟 3**，使用更新後的 `./data/` 重新訓練模型，以期獲得進一步的性能提升。重複此過程（步驟 3 -> 步驟 4 -> 步驟 5 -> 步驟 6 -> 更新數據 -> 步驟 3...）可以不斷優化模型。

**此步驟目的：** 評估自訂模型的效果，並提供一個持續改進模型的路徑。通過不斷地用模型處理新數據，並將驗證過的結果反哺回訓練集，可以逐步提升模型的準確性和魯棒性。

## 注意事項

*   **數據質量是核心**: 無論是初始整理（步驟 2）還是後續迭代（步驟 6），仔細審核和標註數據都是提升模型性能的關鍵。
*   **訓練時間**: 步驟 3 的模型訓練可能需要較長時間。
*   **迭代改進**: 如步驟 6 所述，利用新數據和模型反覆訓練是提高效果的常用方法。
